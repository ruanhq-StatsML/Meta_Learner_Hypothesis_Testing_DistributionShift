# Where the feature / dataset files live

## A. Feature-store delivery (merchant + user rollups) — **in zip**

Path: **`delivery/data/feature_store/`** (also `data/feature_store/` inside `fsds_sot_delivery.zip`).

| File | Content |
|------|---------|
| `users.csv`, `items.csv`, `merchants.csv`, `orders.csv` | Relational tables (user → order → item → merchant, batch `W` on merchant) |
| `merchant_features.csv` | **Pre-aggregated merchant-grain features** (~69 cols: gmv/user_rating/… × mean/std/rolling + activity) |
| `user_features.csv` | **Pre-aggregated user-grain features** (~27 cols) |

**How they were produced:** generated by  
`Python/demo_fsds_feature_store_attribution.py`  
from `feature_store/merchant_prototype.py` (seed `7451`, not imported from an external CSV in this repo).

To **regenerate** the same style of tables:

```bash
cd Python && python3 demo_fsds_feature_store_attribution.py
```

To use **your own pre-built feature matrices**, place CSVs here (or set paths in your script) with:

- Row index = entity id (`merchant_id` or `user_id`)
- Column `W` = batch (0=ref, 1=live) for merchant-level attribution
- Remaining columns = feature-store metrics

There is **no separate checked-in file** in this GitHub repo from an ad-hoc “already featurized” upload outside the demo export above.
