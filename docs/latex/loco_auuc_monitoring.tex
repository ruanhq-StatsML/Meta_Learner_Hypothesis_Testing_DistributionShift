\section{AUUC integral}
$g_k=(\bar Y_{T,k}-\bar Y_{C,k})(n_{T,k}+n_{C,k})$, $\mathrm{AUUC}=\frac{1}{n}\int_0^1 g(f)df$ (trapezoid). Validated vs \texttt{sklift.uplift\_auc\_score(y, uplift, treatment)}.
