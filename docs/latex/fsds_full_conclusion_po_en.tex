\begin{abstract}
\textbf{Conclusion:} One REF/LIVE monitoring spine in this repository supports uplift fulfillment, agent budgeting, and federated blocks.
\textbf{Incremental value} is realized at execution steps---segment/role budgets, REALLOCATE caps, debate early-stop---not at diagnostic statistics alone.
The most \textbf{production-practical} agent patterns are \textbf{ReAct} ($\sim$31\% variable cost/ep in MC with stable success) and \textbf{multi-agent debate} ($\sim$38--39\% \$/debate, +2pp success in extended MC), with encoder-agnostic embedding mapping ($Z$ per segment, $X$ for batch MMD).
Uplift REALLOCATE caps show \textbf{\$3{,}271} simulated OPEX net across four benchmark scenarios; RELEARN remains a separate CAPEX ticket.
All claims below are tied to regenerated Tables R1--R10b in the appendices and to \texttt{impact\_receipt} JSON for audit.
\end{abstract}

\section{Principal conclusions (executive)}

\begin{enumerate}[label=\textbf{C\arabic*.}]
  \item \textbf{One method, many surfaces.} FSDS compares a reference window to a live window on covariates $X$; agent tracks add segment matrix $Z$ for within-episode budgets. Uplift reuses the same localization stack with customer $X$, outcome $Y$, treatment $T$, batch $W$.
  \item \textbf{Dollars follow policies, not alarms.} MMD$^2$, domain AUC, and PO-risk \emph{gate} actions. OPEX increments attach when rules execute: REALLOCATE (\texttt{econ\_bucket=opex}), \texttt{BranchBudget} lists, or early-stop round cuts---each logged on \texttt{impact\_receipt}.
  \item \textbf{ReAct is the default deploy shape.} Tool loops map to three rows of $Z$ (thought, action, observation). Observation drift raises batch MMD on $X$ and segment shift on row~2; FSDS trims thought/action tokens while adding checks on observation---$\sim$31\% cost reduction in collaboration MC without success loss in that run (Table~\ref{tab:practical-react-ma}).
  \item \textbf{Multi-agent collaboration works at two scales.} Micro: per-role $L$/tier (con down-tiered under drift, judge on critical path; Table~\ref{tab:ma-roles}). Macro: $(R,B,d)$ early-stop when round centroids stabilize (Table~\ref{tab:stacked-ma}). Combined MC shows $\sim$38--39\% savings; dedicated artifact adds +2pp success.
  \item \textbf{Embedding type is secondary; mapping is not.} Any $\mathbb{R}^d$ segment vector is valid if production maps phases/roles to fixed rows of $Z$ and builds \texttt{trace\_features} consistently (Appendix~\ref{app:mapping}).
  \item \textbf{When drift is real, MMD rises.} Injected LIVE shift on the intended segment increases $\widehat{\mathrm{MMD}}^2$ between REF and LIVE batches of $X$ and aligns $\arg\max_b s_b$ on $Z$ (Appendix~\ref{app:mapping}, \S\ref{sec:mmd-conclude}).
  \item \textbf{Two-ledger discipline holds.} OPEX caps and agent compute savings reconcile to vendor invoices (\texttt{bank\_cash\_bridge.py}); RELEARN tickets (\$2{,}500$\times$4 in uplift bench) are CAPEX and excluded from OPEX net numerators.
  \item \textbf{Extend scenarios, not the spine.} Add rows to \texttt{agent\_collaboration\_scenarios.json} and config traffic tiers; keep \texttt{covariate\_attribution} + \texttt{fit\_agent\_plan} + receipts unchanged.
\end{enumerate}

\section{Method conclusion (minimal formalism)}

\paragraph{Agent objects.}
$Z\in\mathbb{R}^{B\times d}$ (L2-normalized rows) $\rightarrow$ shift scores $s_b$ and budgets $L_b$.
$X_{\mathrm{ep}}=\mathrm{concat}(\mathrm{mean}(Z),\ \text{scalars})$ stacked into $X_{\mathrm{ref}}, X_{\mathrm{live}}$ $\rightarrow$ batch shift.
$Y$ is task success or conversion (evaluation); batch label $W\in\{\mathrm{REF},\mathrm{LIVE}\}$ is \textbf{not} treatment $T$.

\paragraph{Within-episode budget (conclusion form).}
With centroid $c=\mathrm{mean}_b(\tilde{Z}_b)$,
$s_b=\|\tilde{Z}_b-c\|/\max_{b'}\|\tilde{Z}_{b'}-c\|$ and
$L_b=\mathrm{clip}(\kappa\bar{s}_b q_b \eta_b, L_{\min,b}, C_{\mathrm{lat}})$.

\section{MMD and acceptance (conclusion)}
\label{sec:mmd-conclude}
Batch monitoring uses RBF MMD$^2$ on $X_{\mathrm{ref}}$ vs $X_{\mathrm{live}}$ (implementation \texttt{rbf\_mmd2}):
\[
\widehat{\mathrm{MMD}}^2
= \frac{1}{n_0^2}\sum k(X^0,X^0)
+ \frac{1}{n_1^2}\sum k(X^1,X^1)
- \frac{2}{n_0 n_1}\sum k(X^0,X^1).
\]
\textbf{Conclusion for operators:} treat rising $\widehat{\mathrm{MMD}}^2$ together with overlap ESS and domain AUC as authorization to \emph{localize} (which segment/role/quintile), then apply OPEX policy; do not equate MMD alone with dollar ROI.

\section{Practical deployment conclusions}

\paragraph{ReAct (highest priority).}
Log phase embeddings $\rightarrow$ \texttt{build\_react\_trace} $\rightarrow$ rolling \texttt{fit\_agent\_plan} $\rightarrow$ apply \texttt{intervention.budgets} $\rightarrow$ \texttt{impact\_receipt}. Playbook: budget observation, not thought, when tools drift.

\paragraph{Multi-agent (second priority).}
Log $(R,B,d)$ for stop; final-round $Z$ for budgets; stack receipts for micro vs macro levers separately for finance.

\paragraph{Uplift / credit (same code).}
Frozen $\hat\tau$ on LIVE; gates G0--G3 and LOCO--AUUC localize; step \textbf{R} REALLOCATE for OPEX; RELEARN ticket only after trial windows fail.

\section{What we do \emph{not} conclude}

\begin{itemize}[nosep]
  \item MMD$^2$ or AUUC alone is not cash---receipts and invoices must match.
  \item Federated \$125k/q unlock is a strategic scenario, not additive token math.
  \item Self-consistency MC in one seed trades success for cost; gate on your own $Y$ SLA.
\end{itemize}

\section*{Final statement}
FSDS in this repository is concluded to be \textbf{deployable} where production can supply REF/LIVE batches of $X$, segment rows $Z$, and policy hooks for budgets or caps.
\textbf{ReAct} and \textbf{multi-agent} are the strongest demonstrated collaboration patterns; \textbf{uplift step R} is the strongest campaign pattern; \textbf{MMD rising on $X$} with localized shift on $Z$ is the accepted statistical signature that localization---not blind retrain---is warranted.
