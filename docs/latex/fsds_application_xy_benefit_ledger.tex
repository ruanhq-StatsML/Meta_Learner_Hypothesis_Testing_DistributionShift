\begin{abstract}
This ledger answers three audit questions for each product track: \textbf{(1)} where FSDS runs in production, \textbf{(2)} the exact objects $X$, $Y$, $T$, $W$ (and agent $Z$), \textbf{(3)} which pipeline steps produce \emph{positive benefit}---direct OPEX, outcome quality, communication savings, or strategic preservation---versus steps that only \emph{gate} actions.
Positive benefit is never attributed to monitoring statistics alone; dollars attach to \textbf{rules and budgets} emitted after gates, with \texttt{impact\_receipt} JSON as the audit join key.
\end{abstract}

\textbf{Benefit types:}
\begin{enumerate}[nosep]
  \item[\textbf{B1}] Variable OPEX down (tokens, treatments, uplink bytes billed as \$).
  \item[\textbf{B2}] Outcome up (success rate, conversion; may lag as \texttt{cash\_in}).
  \item[\textbf{B3}] Infra/communication down (federated uplink vs centralized matrix).
  \item[\textbf{B4}] Strategic (avoided wrongful shutdown; requires finance/legal sign-off).
  \item[\textbf{G}] Gate/localize only---benefit is \emph{avoided bad action}, not a standalone ROI line.
\end{enumerate}
