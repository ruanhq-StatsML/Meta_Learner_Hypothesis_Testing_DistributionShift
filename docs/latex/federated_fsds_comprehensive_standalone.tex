\begin{abstract}
We document a \textbf{communication-efficient} federated variant of batch FSDS for vertically partitioned features.
Clients upload only $O(|F_k|)$ attribution summaries per REF/LIVE window---not raw samples---while the server merges global ranks, runs BH-FDR, diagnoses drift type, and emits online feature selection (OFS) actions.
Empirical runs on seven UCI-style benchmarks (WDBC, Wine, Diabetes, Ionosphere, Heart Statlog, Spambase, Sonar) with injected covariate shift show consistent uplink savings on the order of $10^2$--$10^3\times$ versus naive matrix centralization and localize shift in the targeted feature blocks when top-ranked features align with injection (see summary table).
\end{abstract}
